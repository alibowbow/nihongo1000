# 日本語 千日文 — 일본어 천일문 웹앱

핵심 문형 50과 × 1000문장으로 일본어의 뼈대를 세우는 **천일문 방식 학습 웹앱**입니다.
**기초(N5~N3) · 중급(N3~N2) · 최상급(N1)** 코스를 레벨에 맞춰 골라 학습하며, 의존성 없는 순수 정적 사이트(HTML/CSS/JS)라 어디서든 바로 동작합니다.

## 주요 기능

- **가나 익히기 — 五十音**: 히라가나·카타카나·함께 보기 차트(청음/탁음·반탁음/요음 + 특수음 메모)와 **랜덤 연습** — 발음을 가린 채 무작위로 섞인 그리드에서 글자를 탭하면 발음이 재생되고 표기가 나타남
- **단어장 — 語彙**: 숫자·개수 세기·조수사(本/冊/台/匹/枚)·월·날짜·요일·시·분·때 표현(어제~모레, 주/달/해)·계절·날씨·가족·색깔·위치 등 14개 주제 약 260단어. 발음은 기본으로 가려져 있고 단어를 누르면 발음이 재생되며 읽기가 나타남(발음 보이기/뜻 가리기 토글로 자가 테스트)
- **과별 문법 해설 — 文法**: 50과 전 과에 핵심 문형, 의미·용법, 접속·활용표, 학습 포인트, 후리가나 달린 주요 어휘 수록 ([`js/grammar.js`](./js/grammar.js))
- **문법 색인 + 문법 전용 페이지**: 50개 문형을 한눈에 훑고, 본문 없이 해설만 모아 읽는 문법 페이지(이전/다음 문형 이동)
- **천문장 — 全文**: 1000문장을 한 화면에서 통독. 레벨 필터, 과로 바로 이동, 가리기(암송 연습), 문장별 듣기·본문 점프
- **목차 — 五十課**: 문형별 50과, 레벨(N5/N4/N3) 필터와 과별 진도율
- **학습 모드**: 문장 카드 20개씩 · **한국어/일본어 가리기**(블러 → 탭해서 확인) · 발음 듣기(TTS) · 완료 체크 · 북마크
- **암기 모드 — 暗記**: 카드 뒤집기 자가 채점(◯ 알아요 / ✕ 몰라요), 日→韓·韓→日 방향 선택, 랜덤 20 / 챕터 / 북마크 / **복습 대기**(틀린 문장 자동 수집) 출제, 키보드 지원(`Space`/`O`/`X`)
- **자동 학습 — 自動再生**: 손대지 않아도 카드가 자동으로 넘어가며 **일본어 → 한국어를 차례로 음성 재생**(TTS). 재생 범위(챕터/전체/북마크/복습 대기), 한국어 음성 on/off, 일본어 반복 횟수, 속도, 문장 간격, 반복 재생 설정. 재생 중 일시정지·이전·다음·속도 조절(키보드 `Space`/`←`/`→`)
- **검색**: 일본어 · 한국어 뜻 · 문형 · 문장 번호로 즉시 검색
- **대시보드**: 달성률 링, 오늘 학습량, 연속 학습일, 레벨별 진행, 오늘의 문장
- **그 외**: 다크 모드, 글자 크기 조절, 진도 자동 저장(localStorage, 서버 불필요), 모바일 대응(하단 탭 바)

## 실행

빌드 과정이 없습니다. 정적 서버로 열기만 하면 됩니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

### GitHub Pages 배포

저장소 **Settings → Pages → Branch: `main` / root** 선택만 하면 끝입니다.

## 구조

```
1000.md                  # 기초(N5~N3) 원문 1000문장 — 출처 데이터
1000-inter.md            # 중급(N3~N2) 원문 — 단계적으로 채우는 중
1000-adv.md              # 최상급(N1) 원문 — (예정)
index.html               # 앱 셸
css/style.css            # 디자인 시스템 (和紙·墨·朱印 콘셉트)
js/data.js               # *.md에서 자동 생성된 코스 데이터 (수정 금지)
js/grammar.js            # 기초 과별 문법 해설 (직접 집필한 교재 본문)
js/grammar-inter.js      # 중급 과별 문법 해설
js/kana.js               # 가나(五十音) 데이터 — 청음·탁음·요음 104자
js/words.js              # 단어장 데이터 — 14개 주제 약 260단어
js/app.js                # SPA 로직 (라우터·상태·TTS·퀴즈·코스 전환)
scripts/build-data.mjs   # 코스 원문(*.md) → js/data.js 변환기
```

### 코스 체계 (기초 / 중급 / 최상급)

레벨별로 **독립된 코스**를 골라 학습합니다. 각 코스는 자체 1000문장·50과·진도·북마크를 가지며, 홈·목차의 「학습 코스」에서 전환합니다.

| 코스 | 레벨 | 원문 |
|---|---|---|
| 기초 | N5–N3 | `1000.md` (완성) |
| 중급 | N3–N2 | `1000-inter.md` (작성 중) |
| 최상급 | N1 | `1000-adv.md` (예정) |

코스는 `scripts/build-data.mjs`의 등록부에 정의되어 있고, 원문 파일이 존재하는 코스만 빌드에 포함됩니다(미완성 코스도 작성된 과까지 즉시 노출). 기존 사용자의 진도(`localStorage`)는 처음 실행 시 자동으로 기초 코스로 이관됩니다.

원문(`*.md`)을 고친 뒤에는 데이터를 다시 생성하세요.

```bash
node scripts/build-data.mjs
```

배포 직전에는 캐시 무효화를 위해 에셋 버전을 새로 찍습니다(이러면 사용자는 캐시를 비우거나 시크릿 없이, 일반 새로고침만으로 최신본을 받습니다).

```bash
node scripts/stamp-version.mjs
```

## 학습법 (천일문 방식)

1. 일본어 문장을 먼저 **소리 내어** 읽는다.
2. 한국어 뜻을 **가리고** 다시 말해 본다.
3. 문형만 남기고 단어를 바꿔 **내 문장**을 하나 만든다.
4. 하루 20문장 × 50일 = 1000문장 완주.
