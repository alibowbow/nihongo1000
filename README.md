# 日本語 千日文 — 일본어 천일문 웹앱

핵심 문형 50과 × 1000문장으로 일본어의 뼈대를 세우는 **천일문 방식 학습 웹앱**입니다.
**기초(N5~N3) · 중급(N3~N2) · 최상급(N1)** 코스를 레벨에 맞춰 골라 학습하며, 의존성 없는 순수 정적 사이트(HTML/CSS/JS)라 어디서든 바로 동작합니다.

## 화면 구성 — 5개 허브

메뉴는 **5개 허브 + 서브탭**으로 정리되어 있습니다. 모바일·태블릿은 하단에 떠 있는 유리 독, 데스크톱(960px 이상)은 그룹형 사이드바로 같은 구조를 보여 줍니다. 활성 허브를 다시 누르면 허브 처음으로, 다른 허브를 다녀오면 마지막으로 보던 서브탭으로 돌아갑니다.

| 허브 | 서브탭 / 화면 | 주소 |
|---|---|---|
| **홈** | 이어서 학습 · 오늘 목표 · 연속 학습일 · 오늘의 문장 · 레벨별 진도 · 바로가기 | `#/` |
| **학습** | 과별 · 문법 색인 · 전체 문장 (+ 과 본문 · 문법 페이지) | `#/chapters` · `#/chapters?tab=grammar` · `#/all` · `#/study/:과` · `#/grammar/:번호` |
| **어휘** | 단어장 · 가나 | `#/words` · `#/kana` |
| **연습** | 암기 카드 · 자동 듣기 · **복습함** | `#/quiz` · `#/auto` · `#/review` |
| **검색** | 문장 · 문법 · 단어 통합 검색 (어디서든 `/` 키) | `#/search` |

이전 버전에서 쓰던 주소(`#/study/3?focus=812`, `#/words?level=N5`, `#/quiz?src=chapter&ch=3` 등)는 모두 그대로 동작합니다.

## 주요 기능

### 홈 — 오늘의 학습
- **이어서 학습**: 마지막으로 보던 과로 바로 이어가기(진도 막대 포함) + 그 과 듣기 바로가기
- **하루 목표 링**: 오늘 학습한 문장 수를 10 / 20 / 30 / 50문장 목표 대비로 표시(설정에서 변경), 달성 시 진동·안내
- **연속 학습일**: 최근 7일 학습 기록과 연속 일수
- 오늘의 문장, 레벨별 진도, 가나·단어장·문법 색인·자동 듣기 바로가기
- 복습 항목은 홈에 올리지 않았습니다 — 복습은 연습 허브의 「복습함」에서만 다룹니다.

### 학습 — 문형으로 뼈대 세우기
- **목차 — 五十課**: 10과 단위로 묶은 50과, 레벨(N5/N4/N3) 필터, 과 번호·문형·설명 검색, 과별 진도 링
- **학습 모드**: 문장 카드 20개씩 · **한국어/일본어 가리기**(블러 → 탭해서 확인) · 발음 듣기(TTS) · 완료 체크 · 북마크 · 이전/다음 과 이동
- **과별 문법 해설 — 文法**: 50과 전 과에 핵심 문형, 의미·용법, 접속·활용표, 학습 포인트, 후리가나 달린 주요 어휘 수록 ([`js/grammar.js`](./js/grammar.js)). 접고 펼친 상태는 기억합니다.
- **문법 색인 + 문법 전용 페이지**: 50개 문형을 한눈에 훑고, 본문 없이 해설만 모아 읽는 페이지(이전/다음 문형 이동)
- **전체 문장 — 全文**: 1000문장을 한 화면에서 통독. 레벨·상태(전체/미완료/완료/북마크) 필터, 과로 바로 이동, 가리기(암송 연습), 문장별 듣기·본문 점프

### 어휘 — 語彙
- **단어장**: 숫자·개수 세기·조수사(本/冊/台/匹/枚)·월·날짜·요일·시·분·때 표현(어제~모레, 주/달/해)·계절·날씨·가족·색깔·위치 등 14개 주제 약 260단어. 발음은 기본으로 가려져 있고 단어를 누르면 발음이 재생되며 읽기가 나타남(발음 가리기/뜻 가리기 토글로 자가 테스트)
- **가나 — 五十音**: 히라가나·카타카나·함께 보기 차트(청음/탁음·반탁음/요음 + 특수음 메모)와 **랜덤 연습** — 발음을 가린 채 무작위로 섞인 그리드에서 글자를 탭하면 발음이 재생되고 표기가 나타남

### 연습 — 暗記 · 自動再生 · 復習
- **암기 카드**: 카드를 탭해 뒤집고 **좌우로 밀어 채점**합니다(→ 알아요 / ← 몰라요, 가볍게 진동). 버튼·키보드(`Space`/`Enter` 뒤집기, `→`·`O` 알아요, `←`·`X` 몰라요)도 지원. 문장·단어 모드, 日→韓·韓→日 방향, 랜덤 20 / 과 선택 / 북마크 / **복습 대기**(틀린 문장 자동 수집) 출제. 하단에 고정된 시작 바가 선택한 구성을 요약해 줍니다.
- **자동 듣기**: 손대지 않아도 카드가 자동으로 넘어가며 **일본어 → 한국어를 차례로 음성 재생**(TTS). 재생 범위(과/전체/북마크/복습 대기), 한국어 음성 on/off, 일본어 반복 횟수, 속도, 문장 간격, 반복 재생 설정. 재생 중 일시정지·이전·다음·속도 조절(키보드 `Space`/`←`/`→`)
- **복습함**: 복습 대기(틀린 문장) · 북마크 · 단어 복습 대기를 한곳에서 보고, 바로 암기 카드·자동 듣기로 이어서 시작

### 검색
- 일본어 · 한국어 뜻 · 문형 · 문장 번호로 즉시 검색, 문장/문법/단어 구분 칩으로 좁히기

### 설정·개인화
- **코스 전환**: 기초 / 중급 / 최상급 — 코스마다 진도·북마크가 따로 저장되고, 코스 색도 함께 바뀝니다.
- **테마**: 시스템(기본) / 라이트 / 다크 · **글자 크기** · **일본어 음성·톤** · **하루 목표** · **진동 피드백**
- 진도·설정 자동 저장(localStorage `nihongo1000.v1`, 서버 불필요). 이전 버전에서 저장한 데이터는 그대로 이어집니다.

## 디자인 — Sumi Noir

- **먹빛 캔버스 + 빛**: 다크 우선 설계. 깊은 먹색 바탕 위에 코스 색 빛 번짐과 와시(和紙) 질감을 얹었고, 라이트는 기기 설정을 따라가는 「와시 데이라이트」로 같은 위계를 유지합니다.
- **코스별 컬러**: 기초 = 쑥빛(초록), 중급 = 쪽빛(남색), 최상급 = 연지빛(장미). 버튼·진행 링·활성 메뉴·배경 빛이 코스에 맞춰 바뀌고, 로고(주홍 인장)는 항상 그대로입니다. N5–N1 레벨 배지는 구분을 위한 고정색입니다.
- **레이어드 글라스**: 사이드바·독·시트·시작 바에 유리 질감(backdrop blur)과 얇은 하이라이트 엣지, 깊이감 있는 그림자.
- **스프링 모션 + View Transitions**: 화면 전환·시트·세그먼트 컨트롤 이동에 스프링 곡선을 쓰고, 이동 시 부드럽게 이어집니다. 기기가 「동작 줄이기」 상태면 모두 꺼집니다.
- **스포트라이트**: 데스크톱은 커서, 터치는 누른 지점을 따라다니는 은은한 빛(카드 가장자리).
- **서체**: 일본어는 Noto Serif JP(명조 — 다크에서는 한 단계 굵게), 한국어 UI는 Noto Sans KR.
- **접근성**: OKLCH 색 토큰을 생성·검증해 핵심 글자/배경 조합이 WCAG AA 대비를 만족하고, `prefers-reduced-motion` · `prefers-reduced-transparency` · `prefers-contrast` · `forced-colors`에 대응합니다. 화면 이동 시 제목·포커스·스크린리더 안내를 갱신합니다.
- 권장 브라우저: 최신 Chrome · Edge · Safari · Firefox(2024년 이후 버전). View Transitions 등 일부 효과는 지원하지 않는 브라우저에서 생략될 뿐 기능은 동일합니다.


### 코스 체계 (기초 / 중급 / 최상급)

레벨별로 **독립된 코스**를 골라 학습합니다. 각 코스는 자체 1000문장·50과·진도·북마크를 가지며, 상단의 코스 칩(모바일·태블릿) 또는 사이드바의 「학습 코스」(데스크톱)에서 전환합니다. 세 코스 합쳐 **3000문장 · 150과 · 문법 해설 150편**입니다.

| 코스 | 레벨 | 원문 | 포인트 색 | 상태 |
|---|---|---|---|---|
| 기초 | N5–N3 | `1000.md` | 쑥빛 | ✅ 50과·1000문장 |
| 중급 | N3–N2 | `1000-inter.md` | 쪽빛 | ✅ 50과·1000문장 |
| 최상급 | N1 | `1000-adv.md` | 연지빛 | ✅ 50과·1000문장 |

코스는 `scripts/build-data.mjs`의 등록부에 정의되어 있고, 원문 파일이 존재하는 코스만 빌드에 포함됩니다(미완성 코스도 작성된 과까지 즉시 노출). 기존 사용자의 진도(`localStorage`)는 처음 실행 시 자동으로 기초 코스로 이관됩니다.

원문(`*.md`)을 고친 뒤에는 데이터를 다시 생성하세요.

```bash
node scripts/build-data.mjs
```

배포 직전에는 캐시 무효화를 위해 에셋 버전을 새로 찍습니다(이러면 사용자는 캐시를 비우거나 시크릿 없이, 일반 새로고침만으로 최신본을 받습니다).

```bash
node scripts/stamp-version.mjs
```

## 학습법 (천일문 방식)

1. 일본어 문장을 먼저 **소리 내어** 읽는다.
2. 한국어 뜻을 **가리고** 다시 말해 본다.
3. 문형만 남기고 단어를 바꿔 **내 문장**을 하나 만든다.
4. 하루 20문장 × 50일 = 1000문장 완주.
